python is caseSensitive

identifier :
    giving names to variable,fucntion,modules,class etc.. 

Naming Convention:

1. alphabet are allowed (a-z A-Z)
2. can allow numbers (0-9) but cant start with numbers 
3. whitespace character is not allowed 
4. underscore is allowed , can starts with underscore , cannot use special character
5. cannot allowed to use reserved keywords.
